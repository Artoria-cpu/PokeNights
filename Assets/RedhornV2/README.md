## 像素感如何实现

重新制作了 **512 × 512、16 色**图集，并使用 Point / Nearest 采样和无光照材质。图集中保留明确的色块与像素边界，不使用上一版模糊的 AI 贴图；眼睛与服装细节通过重新分配图集区域表达。16 色指创作图集的调色板，屏幕截图仍可能因显示、色彩管理和后处理产生其他颜色。

Unity 材质使用 `Redhorn/Pixel Unlit`，输出贴图颜色乘以材质颜色，默认 Tint 保持白色。不通过法线、高光、AO 或世界阴影给角色颜色增加渐变，也不对整个屏幕做像素化。像素感来自模型表面的图集，角色仍是可自由观察的三维网格。

若把文件导入其他项目，彩色图集应开启 **sRGB (Color Texture)**，设为 **Point**、**Compression: None**，Max Size 不低于原图尺寸。近景检查可关闭 Mip Maps；远景游戏画面需要另行权衡细节与闪烁。使用这张材质不能把已有模糊贴图自动修复为清晰像素画。

## 眼睛、头发与领带

- 眼白和瞳孔是独立部件。眼白固定在头部，两根眼骨只带动像素瞳孔沿脸部左右、上下平移，默认分档移动，保留像素画式注视变化。这不是旋转的仿真球形眼，也没有眨眼、眼睑变形或口型。
- 5 组可摆动发束，每组使用 2 根附加骨骼；贴合头部的发帽保持随头部运动。
- 领带主体使用 3 根附加骨骼，领结留在上身。头发和领带由 `RedhornSecondaryMotion` 在身体动画之后计算有阻尼、有限摆幅的滞后运动，起步、停止、转向和落地时会产生摆动。
- 眼睛由 `RedhornEyeLook` 控制；程序可指定注视目标，或调用 `SetLookNormalized(x, y)` 设置 −1 到 1 范围内的注视方向。预览控制器每帧管理注视目标；单独调用眼睛接口时应先关闭该控制器的目标管理或自行接管它。单独打开 FBX 的动画预览不会自动运行这些 Unity 组件。

领带另外限制了相对胸部的向内附加弯曲，保留向外、侧向摆动。该限位随 UpperChest 动画方向更新。弹簧骨是轻量运动效果，没有布料碰撞、身体碰撞或发束自碰撞。摆幅受到限制，但不保证领带、头发和眼部在所有极端姿态、缩放或高速转向中都无穿插。出现穿插时应先缩小对应摆幅或眼睛位移，再调整初始间距和权重。当前版本未加入手指独立骨骼。

## 身体动作与 Unity 操作

FBX 和 Blender 包含 `Idle`、`Walk`、`Run`、`Prepare`、`Jump`、`Fall`、`Land` 共 7 个动作；`Prepare` 表示起跳准备。身体动作控制躯干和四肢，附加的眼睛、发束、领带由运行时脚本控制。

Unity 资源已放在 `Assets/RedhornV2/`。打开 `Assets/RedhornV2/RedhornV2Preview.unity` 后点击 Play 即可操作；角色预制体为 `Assets/RedhornV2/Prefabs/RedhornV2Player.prefab`。旧的 SampleScene 文件保留。

其他工程可以导入 `RedhornV2_Unity.unitypackage`，其中包含模型、材质、动画状态机、预制体和预览场景。没有在其他 Unity 版本或其他渲染管线中执行整包运行测试。

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 移动、走路。 |
| 按住 Shift 移动 | 跑步。 |
| Space | 跳跃，经过准备、起跳、下落及落地阶段。 |
| 按住鼠标右键拖动 | 环绕观察角色。 |
| 鼠标滚轮 | 调整观察距离。 |

进入 Play Mode 后操作。换用其他控制器时，需要保留 Animator、眼睛和附加骨骼组件，并确认脚本引用指向实际移动的角色根对象。导入设置中的 Optimize Game Objects 应关闭，或明确保留这些附加骨骼供脚本访问。
