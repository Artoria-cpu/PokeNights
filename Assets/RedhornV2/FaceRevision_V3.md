# 红角角色 V3：脸部修订

本版以原始像素参考图左侧人物的平静表情为依据，调整现有 V2 模型的脸。原图带有轻微转头，因此比较重点是眼距、眼形、眉毛、刘海遮挡和下颌比例。鼻子和嘴继续按此前要求弱化。

## 这次调整

- 双眼各向中间移动约 8 mm，拓宽眼形并减小眼睛高度。
- 重做阶梯状上眼睑和独立细眉，去掉原来明显的瞳孔高光。
- 调整额头露出区域，增加较窄、略偏向一侧的中央刘海。
- 收窄下颌两侧，并重新安排面颊像素色块与细小鼻口。

这是三维模型和贴图的实际修改。`脸部_参考与修改前后对比.png` 中的修改前后采用同一相机渲染；原始参考截图按最近邻放大。`Unity_眼睛头发领带.gif` 是新版模型在 Unity 中的运行捕捉。

## 在 Unity 中使用

已经更新本机工程 `E:/unity/saves/My`。打开 `Assets/RedhornV2/RedhornV2Preview.unity`，点击 Play。为延续现有场景和组件引用，V3 继续使用原有 `Assets/RedhornV2/` 路径和资源 GUID；文件夹名称不代表仍是旧脸。

其他工程可导入 `RedhornV3_Unity.unitypackage`，再打开上述预览场景。导入已有 V2 的工程时，资源包会更新相同路径下的资源。运行验证环境是 Unity 6000.3.5f2 / URP。

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 移动、走路。 |
| 按住 Shift 移动 | 跑步。 |
| Space | 跳跃。 |
| 鼠标右键拖动 | 环绕观察。 |
| 鼠标滚轮 | 调整观察距离。 |

像素材质使用 Point / Nearest 采样、sRGB、无压缩、无 Mip Maps，以及 `Redhorn/Pixel Unlit` Shader。眼白固定在头部，眼骨平移像素瞳孔；本版延续原有注视方式，没有新增眨眼或口型。头发与领带保留现有弹簧骨运动和摆幅限制。

## 验证

逐项比较 V2 与 V3 后，仅允许脸、眼白、瞳孔、发帽和两根眼骨的位置变化。其余 24 个网格、36 根骨骼、身体动作曲线、控制脚本和非脸部贴图区域保持一致。Unity 更新沿用已有材质、状态机、场景、预制体和控制参数。

FBX 回读检查通过：30 个蒙皮网格、38 根骨骼、7 个动作（Idle、Walk、Run、Prepare、Jump、Fall、Land）。Unity 虚拟键盘测试通过：走路 1.5 m/s、跑步 3.2 m/s、跳跃高度约 1.10 m；起跳准备、上升、下落及落地状态正常。13 根头发／领带附加骨发生运动，瞳孔及实际瞳孔网格移动约 6 mm，眼白相对头部漂移小于 0.002 mm。

模型保持像素参考的设计方向，三维侧面和遮挡区域仍存在解释性处理；对比图用于判断这次脸部还原的实际程度。
