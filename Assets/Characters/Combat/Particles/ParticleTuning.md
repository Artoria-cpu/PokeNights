# 受击特效手动调参

预制体：`Assets/Characters/Combat/Particles/LimbImpact.prefab`

## 四种尖刺

原图保存在 `ImpactSpikeFourSource.png`。四个区域通过独立材质的 UV 取样，直接使用用户的四个素材；着色器去掉黑色背景，并将彩色区简化成黄橙色块。

在 `02_Rear_Burst` 下：

- `Colour_Spike_1` 至 `Colour_Spike_4`：四种彩色尖刺，各 1 颗。
- `Black_Spike_1` 至 `Black_Spike_4`：对应四种黑色衬底，各 1 颗。
- 八层均在时间 0 发射，黑色层不再依概率出现。
- 旧的 Root_Crown / Main_Spear / Flame_Spray / Black_Spears 已停用，不重复发射。
- 生成半径 0.12，与身上命中层共用生成中心。
- Z 初始旋转 30°–120°，锥形角度 33°。长度 0.28–0.72，宽度 0.18–0.37，寿命 0.50–0.76 秒，均随机。

## 生命周期

- 尺寸从 0 开始，30% 生命周期达到最终尺寸的 80%，之后继续长大。
- 彩色层：最初 2.5% 为白色，至 6.5% 迅速转为素材的黄橙色；85% 后变黑，末尾淡出。
- 黑色衬底从生成时就是黑色，同样从零长大，末尾淡出。
- 使用原生 Color over Lifetime：B 通道控制白闪，R 通道控制最后变黑，Alpha 控制透明度。这个材质中的粒子 RGB 是生命周期控制值，不是普通颜色乘法。
- 两组同时播放，Main / Simulation Speed 均为 1.5，实际寿命为模块时间除以 1.5。

## 手动调整

在对应 Particle System 中调整：数量用 Emission / Bursts，长宽用 Main / 3D Start Size，生命用 Start Lifetime，半径用 Shape / Radius，成长用 Size over Lifetime。圆形光晕和身上两层破碎放射环继续保留。

第五下连击命中时，顿帧为常规命中的 1.35 倍，震动幅度为 1.30 倍，震动持续时间为 0.126 秒。

已确认四个不同素材区域各自同时生成彩色、黑色各 1 颗，尺寸曲线起点为零，着色器无编译错误；已查看游戏相机中的实际粒子画面。

## 命中扩张与飞散（最新）

- 身上两层放射环和接触光晕均从尺寸 0 开始扩张；30% 生命周期达到最终尺寸的 80%。
- 身上金色碎粒每次 18 颗，速度 2.2–3.6；尖刺组金色碎粒每次 22 颗，速度 2.8–4.2，锥角 45°。两组各有 2 颗黑色碎粒。
- 碎粒寿命 0.42–0.65 秒，重力倍率 0.65–0.95；速度逐渐衰减至起始速度的 12%，尺寸从 1 逐渐缩至 0，形成较紧凑的飞散、下落消失过程。整体仍为 1.5 倍速。
