# 非主控角色敌人 AI

三位场景角色均挂载 `PartyEnemyAI`。当前主控角色只接受玩家输入，另外两位自动成为敌人。切换角色时取消旧动作与待执行连击，敌人重新识别新主控，不会沿用上一目标的攻击输入。

## 默认行为

| 设置 | 默认值 |
| --- | --- |
| 发现范围 | 25 米，需视线无遮挡 |
| 脱离范围 | 32 米 |
| 离出生/控制交接位置的最大追击距离 | 40 米 |
| 丢失视线后放弃 | 3 秒 |
| 进入锁定距离 | 6 米 |
| 可出手距离 | 1.25 米 |
| 等待时绕行的理想半径 | 4 米 |
| 绕行速度 | 步行速度的 65%（另叠加距离修正） |
| 左右绕行换向间隔 | 随机 1.8–3.4 秒 |
| 出招前接近的目标间距 | 1.05 米 |
| 首次接近后的等待 | 随机 2–5 秒 |
| 每轮攻击结束后的等待 | 随机 2–5 秒 |
| 第二招概率 | 35% |
| 每轮最大招数 | 2 |
| 对近处攻击尝试闪避的概率 | 45% |
| 闪避冷却 | 随机 2.5–4.5 秒 |
| 闪避反应延迟 | 随机 0.12–0.24 秒 |

每轮从现有五个空手攻击中随机选择起手，第二招接动作列表中的下一招。进入 6 米后保持锁定朝向，等待时持续左右绕行，过近会边后退边侧移，过远会边靠近边侧移。随机 2–5 秒等待结束后进入 Approaching 状态，沿导航路径跑向玩家，在最后 0.45 米减速定位，进入 1.25 米且视线无遮挡才开始挥击。攻击结束后重新绕行等待，遇障碍会沿边走或换向。现有剑为队伍共用的一把，仍由主控持有，AI 使用各角色已绑定的空手动作。

敌人在非出招、非受击期间，看到玩家在近处朝自己攻击时有概率侧闪或后闪。每招只决策一次，有反应延迟及冷却，不会连续无敌闪避；闪避方向先检查导航边界。沿用玩家的方向闪避动作及位移。闪避期间不会接受受击、生成命中粒子、触发顿帧或震动，躲过的同一条剑光也不会在闪避结束后补中。

锁定步行各方向统一为 1.1 秒一步态循环，跑步为约 0.533 秒；等待姿势不再把 16 秒待机周期混入斜向移动。玩家 WA/WD 和敌人侧移使用同一节奏。

## 复用的系统

- 移动、重力和碰撞由 `RedhornPreviewDriver` / CharacterController 处理。
- 锁定使用原有 `combatLookTarget`、`LockBlend`、`LockMoveX/Z`、FightIdle 和眼神目标。
- 动作由 `CharacterComboAttack` 播放，命中由原有接触帧和 `PartyMeleeHitTest` 判定。
- 敌人只攻击当前主控，不互相造成受击；主控仍可攻击所有其他角色。闪避保留原有免受击逻辑。
- 中键玩家锁定现在也可以选中非主控角色。

## 导航与调参

场景的 `Party AI Navigation` 使用 `NavMeshSurface`，按已有物理碰撞体烘焙，包含地面和训练方块；角色与拾取触发器排除在烘焙之外。使用默认人形 Agent Type，路径每 0.25 秒更新，角色仍由已有 CharacterController 驱动，无第二套位移组件。角色之间另有近距离间距避让。

导航数据：`Assets/Characters/Combat/Navigation/PartyNavigation.asset`。场景地形或静态障碍变化后，可调用 `PartyEnemyAIBuilder.Build()` 重烘焙并保存。没有新增跨越缺口或跳跃导航。

所有发现、脱离、锁定、攻击间隔、连击概率参数均可直接在每个角色的 `PartyEnemyAI` Inspector 修改。

目前仍是受击测试战斗，没有添加血量、死亡或胜负规则。后续若要完整战斗，可在此基础上增加这些规则，以及同时进攻的人数限制。
